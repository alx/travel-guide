## GeoJSON POI Schema

Every destination's data lives in `static/<destination>/locations.geojson` as a standard GeoJSON `FeatureCollection`. Each feature must follow this schema:

```json
{
  "type": "Feature",
  "id": "<destination>-<zero-padded-number>",
  "geometry": {
    "type": "Point",
    "coordinates": [longitude, latitude]
  },
  "properties": {
    "id":           "String — same as feature id (required)",
    "name":         "String — place name (required)",
    "category":     "String — must match a known category for the map (required)",
    "icon":         "String — emoji, e.g. '🍽️' (required)",
    "display_name": "String — longer OSM/Nominatim display name",
    "address":      "String — full street address or area description",
    "notes":        "String — insider description, what makes it worth visiting",
    "hours":        "String — opening hours, e.g. '09:00–18:00 daily'",
    "phone":        "String — international format, e.g. '+66 77 256 500'",
    "url":          "String — website or Instagram URL",
    "price":        "String — entry fee or price range, e.g. 'from ฿1,500'",
    "coord_source": "Enum — see below",
    "coord_accuracy": "Enum — 'high' | 'medium' | 'low'",
    "osm_id":       "String or null — OSM node/way/relation ID",
    "osm_type":     "String or null — 'N' | 'W' | 'R'"
  }
}
```

**Coordinate order is `[longitude, latitude]`** — the GeoJSON standard (opposite to Google Maps which shows `lat, lng`).

Only `name`, `category`, `icon`, and `geometry` are strictly required. All other properties are optional but encouraged for quality.

### coord_source enum

| Value | Meaning |
|-------|---------|
| `google_maps_pin` | Dropped pin from Google Maps |
| `nominatim` | Nominatim, LocationIQ, or Photon (OSM-backed) search result |
| `research` | Manual research from web sources |
| `estimated` | Approximate position, neighbourhood level |
| `on_site_gps` | Verified on-site with a GPS device |

### coord_accuracy enum

| Value | Meaning |
|-------|---------|
| `high` | Building or POI-level accuracy |
| `medium` | Street or area level |
| `low` | Town or district level |
