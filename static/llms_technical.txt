## Hugo Layout Structure

Each map is a Hugo section with its own `layouts/<destination>/list.html`. All maps share:

- `layouts/_default/baseof.html` — site shell; injects embed-mode CSS + GitHub config; `{{ block "head" }}`, `{{ block "main" }}`, `{{ block "scripts" }}`
- `layouts/partials/map-toolbar.html` — toolbar with download/GPX/embed/share/load/GitHub
- `layouts/partials/contact-form.html` — floating Formspree contact form
- `layouts/partials/map-geolocation.html` — geolocation JS (`navigator.geolocation`)

Maps call `{{ partial "map-toolbar.html" . }}` inside their `{{ define "main" }}` block and `{{ partial "map-geolocation.html" . }}` at the end of `{{ define "scripts" }}`.

## TopoJSON Format

The fishing-boat expedition uses non-quantized TopoJSON (no `transform`). Arc coordinates are absolute `[lng, lat]` pairs. Two named objects:
- `route` — LineString geometries referencing arc indices; properties: `name`, `day` (int), `color`, `notes`
- `waypoints` — Point geometries with direct `coordinates`; properties: `name`, `category`, `icon`, `notes`, `hours`

Loaded via `topojson.feature(topo, topo.objects.<name>)` from `topojson-client@3`.

## window.MAP_CONFIG

Every map sets a `window.MAP_CONFIG` object consumed by `map-toolbar.html`:

```javascript
window.MAP_CONFIG = {
  title:       'My Map — Maps',   // used in GPX filename + embed preview
  geojsonUrl:  '/destination/locations.geojson',
  geojsonData: null,              // populated after fetch(); used for GeoJSON download
  embedPath:   '/destination/',   // used to build the embed iframe src
  previewImage: '/images/map-previews/my-map.png',  // optional embed preview
};
```
