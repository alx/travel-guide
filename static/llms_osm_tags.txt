## When to use this file

Use when translating a free-text search query (e.g. "yoga studio", "beach bar")
into structured OSM tags for an Overpass QL query. Pick the best-matching
key=value pair(s) from the tables below, then build the query using the
templates at the bottom.

---

## Overpass QL Templates

Endpoint: https://overpass-api.de/api/interpreter
Visual builder: https://overpass-turbo.eu

### Radius search — single tag (recommended)

```
[out:json][timeout:25];
(
  node["{TAG_KEY}"="{TAG_VALUE}"](around:{RADIUS_M},{LAT},{LON});
  way["{TAG_KEY}"="{TAG_VALUE}"](around:{RADIUS_M},{LAT},{LON});
  relation["{TAG_KEY}"="{TAG_VALUE}"](around:{RADIUS_M},{LAT},{LON});
);
out center;
```

### Radius search — multiple tags (OR union)

```
[out:json][timeout:25];
(
  node["amenity"="restaurant"](around:3000,{LAT},{LON});
  node["amenity"="cafe"](around:3000,{LAT},{LON});
  way["amenity"="restaurant"](around:3000,{LAT},{LON});
  way["amenity"="cafe"](around:3000,{LAT},{LON});
);
out center;
```

### Name keyword search (fallback — use when no standard tag fits)

```
[out:json][timeout:25];
(
  node["name"~"{KEYWORD}",i](around:{RADIUS_M},{LAT},{LON});
  way["name"~"{KEYWORD}",i](around:{RADIUS_M},{LAT},{LON});
);
out center;
```

### Bounding box search

```
[out:json][timeout:25];
(
  node["{TAG_KEY}"="{TAG_VALUE}"]({S},{W},{N},{E});
  way["{TAG_KEY}"="{TAG_VALUE}"]({S},{W},{N},{E});
);
out center;
```

## Translation Examples

| Search query | OSM tags to use |
|---|---|
| yoga studio | leisure=fitness_centre + sport=yoga |
| crossfit gym | leisure=fitness_centre + sport=crossfit |
| muay thai gym | leisure=fitness_centre + sport=martial_arts |
| surf school | leisure=sports_centre + sport=surfing |
| beach bar | amenity=bar (near natural=beach, or use name keyword) |
| rooftop bar | amenity=bar (name~"rooftop\|sky\|top") |
| underground music venue | amenity=nightclub OR amenity=music_venue |
| thai massage | amenity=massage OR shop=massage |
| co-working space | amenity=coworking_space |
| street food | amenity=fast_food OR amenity=food_court |
| night market | amenity=marketplace OR shop=market (name~"night") |
| luxury hotel | tourism=hotel (no OSM luxury filter — use name keyword) |
| climbing gym | leisure=fitness_centre + sport=climbing |
| day spa | amenity=spa OR leisure=sauna |
| vegan restaurant | amenity=restaurant + diet:vegan=yes |
| convenience store | shop=convenience |
| 7-Eleven | shop=convenience + name~"7-Eleven" |
